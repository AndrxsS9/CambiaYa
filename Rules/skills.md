# Skills del Agente - Marketplace

Cuando necesites ejecutar una de estas tareas, invoca la skill correspondiente:

| Skill | Prompt Base |
| :--- | :--- |
| **Nuevo Endpoint** | Crea un endpoint Django REST para [recurso]. Sigue las reglas del proyecto. Incluye: modelo, serializer con validaciones, view con IsAuthenticated y URL en /api/v1/[recurso]/. |
| **Componente React** | Crea un componente React para [función]. Usa Tailwind. Textos en español. Llama a la API con Axios usando JWT del AuthContext. |
| **Test Unitario** | Crea tests unitarios en Django para [modelo/endpoint]. Cubre: caso exitoso, datos inválidos y acceso no autorizado. |
| **Migración** | Genera la migración de Django para los cambios en [modelo]. Incluye rollback seguro. |
